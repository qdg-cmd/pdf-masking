====================================================================
  [pdf 마스킹 시스템] GitHub Pages 웹 앱 배포 및 설치 3분 가이드
====================================================================

이 폴더에 있는 파일들은 별도의 빌드 과정 없이 GitHub에 올리기만 하면
즉시 웹 주소로 실행될 수 있도록 100% 최적화된 파일들입니다.

--------------------------------------------------------------------
【 1단계: GitHub 새 저장소 만들기 】
--------------------------------------------------------------------
1. https://github.com 에 로그인합니다.
2. 우측 상단의 [+] 버튼 클릭 -> [New repository]를 선택합니다.
3. Repository name 에 원하는 이름을 영문으로 입력합니다. (예: pdf-mask)
4. 반드시 [Public]에 체크합니다. (무료 계정은 Public이어야 무료 웹 호스팅 제공)
5. 맨 아래 초록색 [Create repository] 버튼을 클릭합니다.

--------------------------------------------------------------------
【 2단계: 파일 업로드 (드래그 앤 드롭) 】
--------------------------------------------------------------------
1. 생성된 첫 화면에서 "Get started by creating a new file or uploading an existing file."
   문구 중 파란색 링크인 [uploading an existing file] 을 클릭합니다.
2. 현재 이 폴더(깃허브_업로드용_파일) 안의 모든 파일과 폴더를 전체 선택(Ctrl + A)합니다.
3. GitHub 웹 브라우저 업로드 영역으로 마우스 드래그 앤 드롭합니다.
   (파일들이 목록에 업로드 완료될 때까지 잠시 기다립니다)
4. 맨 아래 초록색 [Commit changes] 버튼을 누릅니다.

--------------------------------------------------------------------
【 3단계: GitHub Pages 켜기 (주소 생성) 】
--------------------------------------------------------------------
1. 저장소 상단 메뉴 탭에서 [Settings] (톱니바퀴 아이콘)를 클릭합니다.
2. 왼쪽 사이드바 메뉴에서 [Pages] 를 클릭합니다.
3. 'Branch' 항목에서 [None] 으로 되어 있는 셀렉트 박스를 클릭하여 [main] 으로 변경합니다.
4. 바로 옆 폴더는 [ / (root) ] 그대로 두고 [Save] 버튼을 누릅니다.

--------------------------------------------------------------------
【 4단계: 접속 및 컴퓨터에 웹 앱(PWA)으로 설치하기 】
--------------------------------------------------------------------
1. 약 1분 후 페이지를 새로고침(F5)하면 상단에 내 웹 주소가 생성됩니다:
   예) https://내아이디.github.io/pdf-mask/
2. 이 주소를 클릭해 접속하면 CMD 창 없이 완전한 웹 앱으로 작동합니다!
   (다른 컴퓨터, 동료 교사 컴퓨터 등 어디서든 링크만 주면 바로 사용 가능)
3. 브라우저(크롬 또는 엣지) 주소창 맨 우측에 있는 [모니터/앱 설치 아이콘]
   또는 화면 상단에 새로 생긴 [[ 앱으로 설치 ]] 버튼을 클릭합니다.
4. 이제 바탕화면에 "pdf 마스킹 시스템" 아이콘이 생성되며,
   더블 클릭 시 브라우저 주소창이나 탭도 없는 독립 윈도우 앱 창으로 실행됩니다!
