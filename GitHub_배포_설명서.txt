====================================================================
  [pdf 마스킹 시스템] GitHub Pages 웹 앱 배포 및 재배포(업데이트) 가이드
====================================================================

이 폴더에 있는 파일들은 별도의 빌드 과정 없이 GitHub에 올리기만 하면
즉시 웹 주소로 실행될 수 있도록 100% 최적화 및 보안 강화된 배포용 파일입니다.

--------------------------------------------------------------------
【 이미 배포된 웹 사이트에 재배포(업데이트)하는 방법 】
--------------------------------------------------------------------
1. https://github.com 에 로그인한 후 기존에 만들어둔 저장소로 들어갑니다.
2. 화면 우측 상단의 [Add file] 버튼을 클릭하고 [Upload files]를 선택합니다.
3. 현재 이 폴더(깃허브_업로드용_파일) 안의 모든 파일과 폴더를 전체 선택(Ctrl + A)합니다.
4. GitHub 브라우저 화면의 업로드 영역으로 마우스 드래그 앤 드롭합니다.
   (파일들이 목록에 업로드 완료될 때까지 잠시 기다립니다)
5. 맨 아래 초록색 [Commit changes] 버튼을 누릅니다.
6. 약 1분 후 웹사이트 주소로 접속해 새로고침(Ctrl + F5)하면 최신 버전으로 즉시 업데이트됩니다!

--------------------------------------------------------------------
【 처음 배포할 때 (신규 저장소) 】
--------------------------------------------------------------------
1. GitHub 우측 상단 [+] -> [New repository] 클릭
2. Repository name 입력 (예: pdf-mask) 후 반드시 [Public] 체크 -> [Create repository] 클릭
3. 파란색 링크 [uploading an existing file] 클릭 -> 이 폴더의 모든 파일(Ctrl + A) 드래그 앤 드롭 -> [Commit changes]
4. 저장소 상단 [Settings] -> 왼쪽 메뉴 [Pages] -> Branch를 [main]으로 선택 후 [Save]
5. 약 1~2분 후 상단에 생성된 주소(https://아이디.github.io/저장소명/)로 접속!

--------------------------------------------------------------------
【 컴퓨터에 전용 데스크톱 웹 앱(PWA)으로 설치하기 】
--------------------------------------------------------------------
1. 브라우저(크롬 또는 엣지)로 해당 웹 주소에 접속합니다.
2. 주소창 맨 우측의 [앱 설치(모니터 모양 아이콘)] 또는 화면 상단의 [[ 앱으로 설치 ]] 버튼을 누릅니다.
3. 바탕화면에 "pdf 마스킹 시스템" 아이콘이 생성되며,
   이후에는 더블 클릭 시 주소창이나 탭도 없는 독립 윈도우 앱 창으로 실행됩니다!
